# ♞ מאמן השחמט

אתר אימון שחמט אישי, בעברית, עם מנוע שחמט אמיתי (Stockfish) — בנוי כדף סטטי אחד שרץ על GitHub Pages.

**אתר חי:** https://meir1997.github.io/chess-trainer/

האתר מותאם אישית על בסיס ניתוח של 1,053 משחקים מ‑chess.com (משתמש `meirco1997`): הוא מדגיש ניהול זמן, "בדיקת בלאנדר", ואת רפרטואר הפתיחות האישי (London כלבן, סקנדינבית כשחור).

## פיצ'רים

- **לוח מחוונים** — דירוגים, אבחנה אישית, נקודות מוקד, ומעקב התקדמות.
- **שחק נגד המנוע** — Stockfish ב‑5 רמות קושי, בחירת צבע, ביטול מהלך, הצעת מהלך, ו"בדיקת בלאנדר".
- **לוח ניתוח** — הערכת עמדה והמהלך הטוב ביותר; טעינת FEN.
- **חידות טקטיקה** — 10 חידות שכל פתרון שלהן אומת במנוע (מט ב‑1, מט ב‑2, מזלגי פרש).
- **מאמן פתיחות** — קווים אישיים מהלך‑אחר‑מהלך עם הסברים.
- **סופי משחק** — מלך+מלכה, מלך+צריח, קידום חייל, עם תרגול מול המנוע.
- **שיעורים** — עקרונות פתיחה, טקטיקה, אסטרטגיה, ניהול זמן וסופים.
- **סנכרון ענן** — כניסה עם Google שומרת את ההתקדמות ומסנכרנת בין מכשירים (Firebase).

## טכנולוגיה

קובץ `index.html` עצמאי. כללי השחמט: chess.js (מוטמע בקובץ). המנוע: Stockfish.js נטען מ‑CDN ורץ ב‑Web Worker, עם מנוע גיבוי פנימי אם ה‑CDN חסום. הסנכרון: Firebase Auth (Google) + Firestore. אין שרת — הכל רץ בדפדפן.

## הקמת סנכרון הענן (Firebase)

כדי להפעיל את הכניסה עם Google צריך פרויקט Firebase חינמי:

1. צרו פרויקט ב‑https://console.firebase.google.com
2. הוסיפו אפליקציית Web והעתיקו את אובייקט ה‑config.
3. הפעילו **Authentication → Google**.
4. צרו **Firestore Database** והגדירו חוקי גישה כך שכל משתמש קורא/כותב רק את המסמך שלו.
5. הוסיפו את הדומיין `meir1997.github.io` תחת **Authentication → Settings → Authorized domains**.
6. הדביקו את ה‑config למשתנה `FIREBASE_CONFIG` בקובץ `index.html`.

> הערה: אובייקט ה‑config של Firebase אינו סוד — הוא מיועד להיות בקוד צד‑לקוח. האבטחה נאכפת דרך חוקי ה‑Firestore.
