# מאמן שחמט אישי בעברית

אתר: https://meir1997.github.io/chess-trainer/

- puzzles.html: 400 חידות ממשחקי meirco1997, עם רמזים והתאמת רמה.
- chess.html: משחק נגד Stockfish, בחירת רמה וצבע אקראי.
- insights.html: דוח היסטוריית המשחקים וניתוח מדגם.
- classic.html: הגרסה הקודמת נשמרה.

## מצב סנכרון

האתר נגיש מכל מכשיר. ההתקדמות עדיין נשמרת ב-localStorage במכשיר בלבד. Google Auth ו-Firestore טרם הוגדרו. חשבון Firebase הגיע למכסת הפרויקטים; צריך לבחור פרויקט קיים או להגדיל מכסה לפני חיבור. אין לטעון שסנכרון פעיל לפני בדיקת שני מכשירים.
