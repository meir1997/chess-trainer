# מאמן שחמט אישי בעברית

אתר: https://meir1997.github.io/chess-trainer/

- puzzles.html: 400 חידות ממשחקי meirco1997, עם רמזים והתאמת רמה.
- chess.html: משחק נגד Stockfish, בחירת רמה וצבע אקראי.
- insights.html: דוח היסטוריית המשחקים וניתוח מדגם.
- classic.html: הגרסה הקודמת נשמרה.

## מצב סנכרון

כניסה עם Google ושמירה ב-Firestore בפרויקט retzef-habit-tracker, תחת users/{uid}/data/chessTrainer בלבד. כללי הפרויקט הקיימים מגבילים גישה ל-uid של המשתמש. לא שונו חוקי גישה או נתוני אפליקציית Retzef.

החידות מתמזגות אוטומטית; משחק שמגיע ממכשיר אחר נטען בכפתור ייעודי כדי לא לקטוע משחק פעיל. מונים היסטוריים של שגיאות ורמזים מתמזגים לפי הערך הגבוה ביותר, ולכן אינם סכום מדויק של תרגול במקביל. ניצחונות/פתרונות נשמרים בעת מיזוג. בלי רשת נשמר מקומית ומנסה שוב כשהחיבור חוזר. אותו חשבון Google נדרש בכל מכשיר.

הגרסה הקודמת classic.html שומרת את התקדמותה מקומית בלבד.
